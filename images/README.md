# GUI artwork

This directory includes the card, wonder and resource images used by the
7 Wonders Second Edition (2020) desktop GUI. They are loaded automatically.

The files are unchanged copies of the local reference assets whose source URLs
and SHA-256 checksums are recorded in
[`data/bga-second-edition/reference/manifest.json`](../data/bga-second-edition/reference/manifest.json).
The original filenames are retained; `cards_v2.jpg` and `boards_v2.jpg` contain
WebP data, which Pillow decodes automatically.

The artwork retains the copyright of its original rights holders;
the GPL license for the simulator code does not relicense these images.
This is an unofficial project with no publisher or platform affiliation.
